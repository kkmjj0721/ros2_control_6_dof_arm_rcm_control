# ros2\_control\_6\_dof\_arm\_rcm\_control

## 📝 项目介绍：

- **核心目标**：本项目旨在基于 `ros2_control` 框架，为六轴机械臂开发并实现 RCM 控制算法；

- **拖动示教与标定**：引入**重力补偿模式**，抵消机械臂自重，允许用户通过直接拖动机械臂，在物理空间中直观地进行不动点（RCM约束点）的末端坐标标记；

- **柔顺交互**：结合**阻抗控制**算法，使机械臂在运动和受力时具备柔顺性，提高与外界环境（或人员）交互的安全性与鲁棒性；
